# AI Academy PRO: guided demonstration

Real Python execution in the browser. This limited lesson uses no model calls and no production student records.

## A focused walkthrough

1. **Read.**
2. **run the seeded bug.**
3. **inspect a failure.**
4. **edit.**
5. **pass.**
6. **see progress.**

Pause on the evidence at each decision: python in a disposable worker; execution timeout and recovery; rtl interface with ltr code.
